Politique de confidentialité

Cette page explique quelles données sont traitées lorsque vous visitez flovaagency.com, pourquoi elles le sont, combien de temps elles sont conservées et comment exercer vos droits.

Dernière mise à jour : 20 novembre 2026.

Responsable du traitement

Le site flovaagency.com est édité par Flova (nom commercial). Aucune autre dénomination sociale n'est publiée sur ce site.

Pour toute question relative à vos données, vous pouvez nous écrire à l'adresse e-mail affichée sur le site, ou utiliser le formulaire de contact disponible sur la page d'accueil.

Formulaire de contact

Lorsque vous remplissez le formulaire de contact, les informations suivantes sont collectées :

  • nom et prénom ;
  • entreprise ou marque ;
  • adresse e-mail ;
  • téléphone ;
  • message (secteur, offre souhaitée, description du projet).

Ces données sont utilisées uniquement pour répondre à votre demande et vous adresser une proposition. Elles ne sont jamais revendues ni transmises à des fins publicitaires.

Elles sont conservées 24 mois à compter du dernier échange, puis supprimées.

Statistiques de visites

Le site mesure son audience à l'aide de compteurs anonymes par jour. Ces compteurs enregistrent uniquement des totaux :

  • nombre de visites ;
  • type d'appareil (téléphone ou ordinateur) ;
  • langue du navigateur ;
  • provenance de la visite (lien direct, moteur de recherche, réseau social) ;
  • sections de la page consultées.

Aucun cookie n'est déposé pour ces statistiques. Aucune adresse IP n'est conservée. Ces compteurs ne permettent pas de vous identifier.

Connexion à l'espace d'édition

L'espace d'édition du site est réservé aux personnes autorisées. La connexion se fait soit avec un compte Google, soit avec un code envoyé par e-mail.

Dans les deux cas, seule l'adresse e-mail est utilisée, dans le seul but de vérifier que la personne a le droit de modifier le site. Aucune autre donnée du compte Google n'est consultée ni conservée.

Hébergement et sous-traitants

Pour fonctionner, le site s'appuie sur les prestataires suivants :

  • GitHub Pages — hébergement des pages du site ;
  • Supabase — base de données et authentification, hébergées dans l'Union européenne ;
  • Resend — envoi des e-mails (réponses aux demandes et codes de connexion).

Ces prestataires agissent en qualité de sous-traitants et ne traitent les données que pour le compte de Flova.

Vos droits

Conformément au Règlement général sur la protection des données (RGPD), vous disposez des droits suivants :

  • accès à vos données ;
  • rectification des données inexactes ;
  • effacement de vos données ;
  • opposition au traitement.

Pour exercer ces droits, adressez votre demande par e-mail à l'adresse affichée sur le site. Nous répondons dans les meilleurs délais.

Si vous estimez que vos droits ne sont pas respectés, vous pouvez introduire une réclamation auprès de l'Autorité de protection des données (Belgique) — autoriteprotectiondonnees.be.

Cette politique peut être mise à jour pour refléter une évolution du site ou de la réglementation. La date de dernière mise à jour figure en haut de cette page.
